# Review brief: user view

**Purpose:** Does this project work for its target user, from first
contact to the main task?

**Scope:** Everything the target user sees: README or landing page,
install or start-up, the main flows, error messages, help. The target
user is described under "Goal" in `AGENTS.md`: here, players (in a
terminal or a browser) and story authors (README, `check_story`).

**Steps:**
1. Become the target user. Note what they know and don't know.
2. Start where they start (README, store page, URL, command) and follow
   the path to the main task without using inside knowledge.
3. Note each point where they would get stuck, guess, or give up.
4. Try the obvious wrong turns: bad input, skipped steps, a small screen,
   no network.
5. Check the wording: jargon, inconsistent names, messages that don't say
   what to do next.

**Output:** see `README.md`.
