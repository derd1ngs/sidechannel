# Review brief: consistency

**Purpose:** Do the deliverables, the recorded decisions and the agreed
baseline still match each other?

**Scope:** The deliverables, `DECISIONS.md`,
`AGENTS.md` and `PLAN.md`. "Baseline" means whatever the project agreed to
deliver (goal, spec, requirements), as named in `AGENTS.md`.

**Steps:**
1. For each active entry in `DECISIONS.md`, check the deliverables follow
   it. Flag decisions that were never carried out or were quietly
   reversed, and superseded entries not marked as such.
2. Check the deliverables against the baseline: missing parts, parts
   nobody asked for.
3. Check the document roles in `AGENTS.md`: to-dos or status inside
   deliverables, the same fact kept in two places, history inside a
   current-state file.
4. Check that `STATUS.md` and `PLAN.md` match the git log.

**Output:** see `README.md`.
